# Wonder movies - spoken descriptions

Authoring source for the paragraph CAI reads on demand for a world wonder or
natural wonder movie, the way the Great Work Showcase reads an image
description. One static paragraph per wonder, keyed by the game's
`BuildingType` or `FeatureType`. The game speaks the wonder's name first and
the Civilopedia carries the history, so the paragraph is about the picture:
what the movie shows, in order, with the real place's features named.

Generated by `scripts/Build-WonderDescriptions.py` from the JSON files that
`scripts/Describe-WonderVideos.py` writes (Gemini 3.1 Pro over the clips cut
by `scripts/Extract-WonderVideos.py`). The "Seen" line is the model's own
list of what it noticed, kept as a review aid. The movies are engine-rendered
and the land around a wonder belongs to the player's map, so each prompt
limits the setting to what the game's placement rules guarantee; see the
`setting` field in `scripts/wonder-video-sources.json`.
