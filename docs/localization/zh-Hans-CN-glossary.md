# Simplified Chinese Accessibility Glossary

This glossary records CAI-specific wording that cannot be copied directly from
a Firaxis localization tag. Official Civilization VI names take precedence for
game concepts such as units, technologies, civics, districts, yields, and
rulesets.

- **Accessibility Mod: 无障碍模组.** The mod and its Civilopedia section.
- **Civilization VI Accessibility Integration: 《文明 VI》无障碍整合.** The localized product name used in mod metadata and update messages.
- **Screen reader: 屏幕阅读器.** Software such as NVDA that speaks UI content.
- **Widget / control: 控件.** A focusable or readable interface element.
- **Container: 容器.** A control that owns other controls for navigation.
- **Focus: 焦点.** The control currently receiving keyboard input.
- **Focus path: 焦点路径.** The nested route from the current screen to the focused control.
- **Focused Widget Reader: 焦点控件阅读器.** The command that reads detailed focused-control content one section at a time.
- **Role: 角色.** The control type announced by the screen reader.
- **State: 状态.** Information such as enabled, disabled, checked, or expanded.
- **Tooltip: 工具提示.** Additional help or descriptive text associated with a control.
- **Input Help: 快捷键参考.** The Ctrl+H view listing general and screen-specific commands.
- **Type-ahead: 按键搜索.** Direct typing that moves to a matching list or tree item without opening a search panel.
- **Navigation cursor: 导航光标.** The independent map cursor used without changing the selected city or unit.
- **Surveyor: 测绘仪.** The circular summary around the navigation cursor.
- **World Scanner: 世界扫描器.** The map-wide known-object browser.
- **Map tac / map pin: 地图标记.** Civilization VI's labeled map marker.
- **Bookmark: 书签.** A numbered slot backed by a player-owned map marker.
- **Panel: 面板.** A top-level or major interface region.
- **Dialog: 对话框.** A temporary panel containing a message or choice.
- **List: 列表.** A single vertical sequence of items.
- **Tree view: 树视图.** A hierarchy with expandable branches.
- **Table / data table: 表格.** Records organized into sortable rows and columns.
- **Grid: 网格.** A spatial row-and-column layout such as a technology tree.
- **Graph view: 关系图.** A prerequisite relationship view navigated along connecting edges.
- **Dropdown: 下拉框.** A collapsed list used to select one value.
- **Submenu: 子菜单.** A list item that expands into another option list.
- **Tab / tab control: 选项卡 / 选项卡控件.** A page selector and its page container.
- **Edit box: 编辑框.** A writable or read-only text field.
- **Static text: 静态文本.** Readable information that has no action.
